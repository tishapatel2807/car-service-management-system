# 🚗 Car Service Management System

A C++ based **Car Service Management System** developed as a console application to manage customers, vehicles, service bookings, service packages, service rates, invoices, and administrative activities.

## 📌 Project Overview

The Car Service Management System provides separate functionalities for **Admin** and **Customers**. It uses C++ Object-Oriented Programming and file handling to store and manage application data.

## ✨ Features

### 👤 Customer Module

- Customer Registration
- Customer Login
- Forgot Password
- Customer and Vehicle Information
- Car Service Booking
- Service Package Selection
- Service Charges
- Invoice Viewing
- Payment Status
- Customer Activity
- Logout

### 🔐 Admin Module

- Admin Login
- Manage Service Packages
- Add, Update and Delete Services
- Manage Service Rates
- View Customer Activities
- Manage Invoices
- Update Payment Status
- Logout

## 🛠️ Technologies Used

- **Language:** C++
- **Programming Concepts:** Object-Oriented Programming
- **Data Storage:** File Handling
- **Libraries:** STL, Regular Expressions
- **Application Type:** Console Application
